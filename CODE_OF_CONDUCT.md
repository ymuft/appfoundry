# Code of Conduct

AppFoundry aims to be a practical, welcoming open-source project where people can learn, contribute, and review security-sensitive code without unnecessary friction.

## Expected behavior

Contributors, maintainers, and participants are expected to:

- discuss ideas and code respectfully
- give technical criticism without attacking the person behind the contribution
- assume good faith while still reviewing security-sensitive changes carefully
- keep issue and pull-request discussions focused on the project
- welcome newcomers and explain project conventions when needed
- credit other people's work and prior art appropriately

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate disruption, spam, and repeated hostile or demeaning behavior are not acceptable in project spaces.

Security reports must follow [SECURITY.md](SECURITY.md) rather than being disclosed in public issues.

## Enforcement

Project maintainers may edit or remove comments, close discussions, reject contributions, or restrict participation when behavior materially harms the project or its community.

If a moderation concern should not be discussed publicly, contact the maintainer through the private contact method listed in the repository's security policy.

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other project-controlled spaces.
